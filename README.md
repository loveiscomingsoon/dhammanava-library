# ธรรมนาวา
หนังสือธรรมประกอบการฟังเสียงธรรมะบรรยายจากพระอาจารย์ต้น

รวบรวมโดยกลุ่มคณะสัทธา นกกระยางขาว

## เว็บไซต์
โฟลเดอร์ docs เป็นหน้าเว็บพร้อมเสียง หนังสือ PDF และหน้าปก ชุดธรรมปัญญา 6 ตอน
เปิด GitHub Pages จาก branch main /docs
เนื้อหาเป็นฉบับสรุปเรียบเรียง รอตรวจทานกับเสียงต้นฉบับ

## ข้อมูลทั้งหมด
archive เก็บชุดสำรองข้อมูลทั้งหมด รวมทะเบียน คำบรรยายอัตโนมัติ และเสียงที่มีอยู่
manifest.json ระบุลำดับและค่า SHA256 ของแต่ละส่วน นำส่วนมาต่อกันตามลำดับก่อนแตก tar.gz
อย่านำ archive ไปเป็นเนื้อหาเว็บไซต์
