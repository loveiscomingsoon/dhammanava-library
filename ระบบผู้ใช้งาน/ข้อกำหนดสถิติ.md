# ระบบผู้ใช้งานและสถิติ ธรรมนาวา

สถานะ: เตรียมข้อกำหนดแล้ว ยังไม่ได้เชื่อมระบบเก็บสถิติออนไลน์

## ข้อมูลที่ต้องแสดงแก่ผู้ดูแล
- จำนวนครั้งเปิดหน้าเว็บ และจำนวนครั้งเข้าใช้งาน แยกจากจำนวนคน
- ผู้เข้าชมไม่ซ้ำ: ประมาณจากรหัสเบราว์เซอร์เท่านั้น ไม่อ้างว่าเป็นจำนวนคนจริง ผู้ใช้หนึ่งคนอาจใช้หลายเครื่อง
- จำนวนสมาชิกจริง: นับบัญชีที่ยืนยันแล้ว เฉพาะกรณีเปิดระบบสมาชิก
- จำนวนเริ่มฟังและฟังจบ แยกตามรหัสตอน
- จำนวนเปิดหนังสือ PDF แยกตามรหัสตอน (ไม่อ้างว่าอ่านจบ)
- สรุปรายวัน รายเดือน ตามเวลา Asia/Bangkok และส่งออก CSV

## การจัดเก็บ
เก็บสถิติและบัญชีในฐานข้อมูลออนไลน์แยกจาก GitHub Pages
ไม่เก็บอีเมล รหัสผ่าน โทเค็น หรือรายชื่อสมาชิกใน GitHub สาธารณะ
หน้าสถิติรวมสำหรับผู้ดูแลต้องตรวจสิทธิ์จากระบบออนไลน์
จำนวนบนหน้าสาธารณะต้องเป็นผลรวมที่ระบบอนุญาตให้เปิดเผย
การจำตำแหน่งฟังบนเครื่องเดิมที่มีอยู่แล้วไม่ใช่ระบบสมาชิก

## เหตุการณ์
page_view: เปิดหน้าเว็บ
session_start: เริ่มช่วงการใช้งาน
listen_start: เริ่มฟังตอนครั้งแรกในช่วงการใช้งาน
listen_complete: เสียงเล่นถึงท้ายตอน ต้องกรองการเลื่อนไปท้ายโดยไม่ได้ฟัง
pdf_open: กดเปิด PDF

## ข้อที่รอคำตอบ
ผู้ฟังสมัครบัญชี หรือเข้าชมโดยไม่ต้องสมัคร
