# GoatCounter
บัญชี: dhammanava-library
แดชบอร์ด: https://dhammanava-library.goatcounter.com/
ติดตั้งสคริปต์ในแอปและไฟล์เตรียมเผยแพร่แล้ว
นับเปิดหน้าเว็บตามค่าเริ่มต้นของ GoatCounter
เหตุการณ์ listen-start-DP-xx: เริ่มฟังแต่ละตอน อย่างมากครั้งเดียวต่อตอนต่อการเปิดหน้า
เหตุการณ์ pdf-open-DP-xx: กดเปิดหนังสือ ไม่ได้หมายความว่าอ่านจบ
ไม่นับเหตุการณ์ทดสอบบน localhost และ 127.0.0.1
ไม่รายงานฟังจบ เพราะยังไม่ได้ตรวจการฟังต่อเนื่องจริง
สถานะ: ยังไม่ยืนยันการรับข้อมูลจากเว็บออนไลน์ เพราะยังไม่ได้เผยแพร่ GitHub Pages
